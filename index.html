chiara-speech2text

Open-source speech2text toolkit for users with atypical speech

Author: Luca Randazzo

The open-source code and instructions can be found at the

chiara-speech2text is an open-source software toolkit to help Chiara (and other users with atypical speech) easily communicate via automatic speech recognition (ASR).

In the left video, Chiara uses the system to communicate with Rosaria, a deaf friend. Before this system, Chiara could communicate with her only in person - because Rosaria must carefully watch Chiara’s lips speaking to understand. Thanks to chiara-speech2text, Chiara can now communicate with people who -otherwise- she would not be able to communicate with.

Background

Chiara is a very active girl with a passion for chatting and making new friends :)
Unfortunately, due to cerebral palsy, she suffers from dysarthria and atypical speech: she has difficulties with articulation (pronunciation), fluency (speech rate and rhythm), abnormal tone, and echolalia (repetitions).
Chiara is not able to write nor read, hence she can only communicate via speech (e.g. voice messages through her tablet, via Whatsapp). However -due to her dysarthria- people have quite some difficulties understanding her voice messages, and existing speech recognition systems perform very poorly in recognizing her speech.
Due to this, her possibilities to communicate and interact are limited, which greatly limits her social interactions.

Proposed solution

chiara-speech2text is a set of open-source software tools to help Chiara (and other users with atypical speech) communicate digitally via ASR.
A custom Android keyboard acts as main user interface, enabling to transcribe user's speech seamlessly within standard communication apps - such as Whatsapp. The keyboard allows to transcribe speech without exiting the communication app - to overcome limitations of other ASR tools (which require users to exit the app, use an external web-transcription-service, and copy/paste the transcription back to the communication app).
Beyond the keyboard, the system has several modules to enable ASR, including functionalities to:

  • record and curate data (i.e. record labeled user's speech, clean and label data) useable for models fine-tuning
  • fine-tune voice-recognition models (e.g. OpenAi Whisper) to user's specific speech
  • perform transcription on a remote server (for lightweight processing on users' device e.g. tablet)
  • spellcheck and provide context-aware corrections of transcripts via remote LLMs

To enable back and forth written communication, Chiara sends written messages through this system, and listens to content of her screen via chiara-select2speak
NOTE: This project uses OpenAI Whisper models for speech recognition. Given enough data from end-users, any language supported by Whisper (e.g. German, Spanish, French, etc) could be used.

Frontend


The frontend allows users to upload custom words/phrases - to train models to their own chosen vocabulary
The frontend allows to curate audio recordings: listen, edit transcripts, delete low-quality data not suitable for training

Keyboard


The keyboard allows to substitute words with similar ones (based on Levenshtein distance), to facilitate corrections
The keyboard allows to write using normal keys

The keyboard supports emojis
The keyboard can be configured through settings

Analysis tool

Performance of the system (e.g. WER) can be explored via a custom analysis tool
